## ⚡ Tính Năng Chính

| Tính Năng | Mô Tả Ngắn Gọn |
| :--- | :--- |
| 🛰️ **Đo GPS Chuẩn Xác** | Lọc chống giật lag Kalman, nhận diện 4 trạng thái (*Đứng yên, Đi bộ, Chạy bộ, Bứt tốc*). Chạy ngầm liên tục và thông báo nhảy số từng giây ngoài màn hình khóa. |
| 🎥 **Video Lộ Trình 3D** | Mô phỏng 3D góc nhìn *Theo dõi* & *Toàn cảnh* (Strava Style). Tải video MP4 60FPS về máy để chia sẻ mạng xã hội. |
| 📊 **Phân Tích Từng KM** | Tự động chia chặng mỗi 1km, so sánh nhịp Pace, đánh dấu **Best Split 🔥** và bảng tổng kết rõ ràng. |
| 🎙️ **Voice Coach Tiếng Việt** | Giọng nói truyền cảm hứng qua từng cột mốc km và nhắc nhở: *"Chào [Tên], đã đến giờ chạy rồi. Cùng xỏ giày và bứt phá hôm nay nhé!"* |
| ⏰ **Chống Quên & Nhắc Nhở** | Tự động chốt phiên chạy theo giờ cài đặt (chống quên tắt app) và chuông báo nhắc nhở tập luyện hàng ngày. |
| 📈 **Thống Kê & Đồng Bộ** | Biểu đồ tiến độ ngày/tuần/tháng/năm, lịch tập luyện, lưu Offline-First và đồng bộ tức thì lên Cloud. |
| 🛡️ **Quản Trị Hệ Thống** | Trang Admin phân quyền riêng biệt để quản lý cộng đồng runner. |

---

## 🛠️ Công Nghệ Nổi Bật

- **Frontend**: Flutter & Dart (Tối ưu 60–120 FPS, UI Dark Neon thể thao).
- **Backend & Auth**: Supabase (PostgreSQL, Realtime Sync, Cloud Storage).
- **GPS & Sensor**: Geolocator + Bộ lọc Kalman 2D chống trôi dạt.
- **Audio & Media**: Flutter TTS (Giọng nói tiếng Việt) & Quick Video Encoder (Xuất video 3D).

## 🚀 Cài Đặt Nhanh

```bash
# 1. Clone dự án
git clone https://github.com/leliendaii/running.git

# 2. Cài đặt thư viện
cd running && flutter pub get

# 3. Chạy ứng dụng
flutter run
```
